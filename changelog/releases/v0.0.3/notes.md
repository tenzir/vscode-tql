# VS Code TQL v0.0.3

This is the initial release of the VS Code extension for Tenzir Query Language syntax highlighting.

## 🚀 Features

### Initial VS Code TQL extension

The first release adds a VS Code extension that recognizes `.tql` files and provides TextMate syntax highlighting for Tenzir Query Language.

_By @dit7ya in #1._

## 🔧 Changes

### Continuous marketplace publishing

The extension can now be published through the release workflow, making marketplace releases reproducible from GitHub.
